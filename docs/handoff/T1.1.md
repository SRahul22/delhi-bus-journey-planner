# T1.1 Quantile model (V2_BAND)

Owner: ml. Branch v2/ml. Flag: `V2_BAND` (0 default = v1; 1 = band). Status: done, validated on 19-24 Oct.

## What changed
- `model/v3/v2/scripts/band_v2.py`: XGBoost `objective="reg:quantileerror"`, `quantile_alpha=[0.5, 0.85]`, same 20
  features and target log(actual / sum of segment medians) as `xgb_final.py`, same split (train days 1-18 = folds 1-3,
  validation 19-24 = fold 4). Params: depth 8, lr 0.05, min_child_weight 100, subsample/colsample 0.8, lambda 10, GPU.
  Early stopping (50 rounds) on validation pinball loss (xgboost `quantile` metric, mean over both alphas) → 104 rounds.
  Final model refit on days 1-24 with 104 rounds → `xgb_quantile.json` (4.5 MB).
- `model/v3/predict.py`: new `band(route, board, alight, depart_dt, base_median_s, base_mean_s, ...) -> (p50_s, p85_s)`.
  p50 = existing `correct()` (unchanged; V3_MODE as before). p85 = max(p50, base × exp(q85 + shift)), shift from T1.2.
  With V2_BAND=0 it returns (p50, None) so callers keep v1's p85. Quantile booster forced to CPU, 1 thread
  (GPU single-row predict was 24 ms/leg; now 1.4 ms/leg for p50 + p85, 0.25 ms for p50 alone).
  Legs not in the v3 patterns: p85 = max(p50, base_median_s × exp(fallback_log_ratio[bucket|peak])).
  Artifacts read from `V2_BAND_DIR`, else `MODEL_DIR\v2` if it holds `xgb_quantile.json`, else `model/v3/v2/`.
- `model/v3/v2/tests/test_band.py` (pytest, 5 tests: p85 ≥ p50, fallback, peak definition, shift keys, flag off).

## Validation (days 19-24, 300k rides, 1-18 models). Full tables in `model/v3/v2/band_val.json`
| Band | coverage ≤ p85 | share ≤ p50 | width (p85−p50)/p50 | pinball@0.85 (s) |
|---|---|---|---|---|
| v1: sum of segment p85s (p50 = sum of medians) | 86.0% | 44.9% | 0.326 | 79.6 |
| quantile q85, no shift | 84.9% | 54.0% | 0.245 | 75.8 |
| quantile + OOF conformal shift (T1.2, clean) | 85.6% | 54.0% | 0.257 | 76.1 |
p50 in the quantile rows = 1-18 L1 XGBoost with the every-10 tree count (13.46% median APE; see T0.4).
Same coverage as v1 with a 21% narrower band and lower pinball loss.
