# T0.5 One-command report (eval) -- done (code); run on val only

## What changed
- `eval/report.py --set val|test` writes `docs/results/v2_<date>_<set>.md` with:
  1. ride error by ride-length bucket (n in every column) for GTFS schedule, sum of medians, sum of means, blend
     600 s and (test only) the final XGBoost, plus peak/off-peak and median bias;
  2. v1 ride band metrics by bucket: coverage, width, pinball@0.85, share under p50/p85/p90;
  3. door-to-door from `realized_<set>.csv`: share scored, pairs scored on >= 3 days, error/bias of total, wait, ride
     and transfer for direct vs transfer journeys (pairs, random, all), door-to-door band calibration
     (v1 `duration_p85_s`), and a bucket x peak table;
  4. the noise floor (runs `eval/noise_floor.py`).
- Reuses `eval/metrics.py` (T0.3) and `eval/ride_baselines.py` (T0.4). Realized journeys are read, not recomputed
  (run `eval/realized_journeys.py` first, ~25 min).
