# T1.2 Conformal shifts (amendment A2: out-of-fold scores)

Owner: ml. Branch v2/ml. Flag: `V2_BAND` (shared with T1.1). Status: done; validated on 19-24 Oct. Gate G1 is for humans.

## What changed
- `model/v3/v2/scripts/band_v2.py` (second part). Scores s = log(actual/base) − q85 are **out of fold** (A2):
  - `shifts` (served): 4 quantile models, each trained on 3 of the 4 six-day folds of days 1-24, predicting the 4th
    (1.2M rides). Served together with the 1-24 quantile model.
  - `shifts_18` (validation only): 3 models on 2 of folds 1-3 each → shifts from days 1-18 only, then the 1-18 model +
    shifts_18 is scored on days 19-24. This is the clean validation number (no 19-24 data in the calibration).
  - Per bucket × peak: shift = ⌈(n+1)·0.85⌉-th smallest score. Cells with n < 500 are pooled with the neighbouring
    bucket (never needed: smallest cell n = 17,415). Bucket = **predicted** p50 (base × exp(q50)), because serving
    cannot key on the actual time. Peak = weekday (not 2/20 Oct) departures 08:00-10:59, 17:00-20:59.
  - Also `fallback_log_ratio`: conformal 0.85 quantile of log(actual/base) per bucket(base) × peak, for legs predict.py
    cannot locate.
- Output `conformal_shifts.json` (contract 3), copies in `E:\hackathon-work\v2\ml\` and `model/v3/v2/`.

Served shifts (log space): <10 off 0.003, 10-30 off 0.001, 30-60 off −0.004, >60 off −0.013; peak 0.019 / 0.024 /
0.026 / 0.024. The quantile model is already close to calibrated; shifts mainly add ~2% for peak.

## Open issues (for G1 reviewers)
- **Bucket definition matters for G1.** By predicted length, coverage is 85-89% in every bucket. By *actual* length it
  cannot be 82-88% everywhere for any honest predictor (conditioning on the outcome: long actual rides are mostly
  rides that ran slow), so >60 actual is 67%. Eval/humans should state which bucket G1 uses; I recommend predicted.
- Day-level variation is larger than the calibration error: Dussehra and its eve (19-20) 90-93%, Saturday 24 Oct 73%.
  A holiday/day-type feature (see T0.4) would help more than finer cells.
- Pinball/coverage use the 1-18 models; the served 1-24 models are not validated on any held-out days (by design, A2).
