# T3.4 Live interface (contract 4) (realtime) — done

## What changed
- `realtime/live_api.py` (new): `LiveInterface(live_state)`
  - `segment_state(seg_id, now, horizon_s) -> (log_ratio, var)`; seg_id = flat index or `(route_id, from_stop_id, to_stop_id)`. kf mode: Kalman forecast and state variance P(h) (state uncertainty of the mean log ratio, NOT including per-traversal noise R = sigma^2 from p50/p85). ratio mode: v1 ratio x v1 horizon fade; var = 22-Oct predictive variance of segment log ratios by horizon minus median R (about 0.06-0.07), floor 0.005. Unknown segment / no snapshot: (0.0, 0.09).
  - `next_buses(stop_id, route_id, now) -> [(eta_s, sd_s), ...]` soonest first, eta from `now` (snapshot lag subtracted, floored at 0).
- `realtime/service.py`: `RealtimeService.api` (rebuilt with the planner copy; `reload()` also refreshes KF sigmas).
- `realtime/next_bus_sd.json`: residual table from 22 Oct (copied from `E:\hackathon-work\v2\realtime\next_bus_sd.json`).
