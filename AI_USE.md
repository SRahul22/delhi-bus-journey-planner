# Use of AI

The project was conceptualised, designed, and directed by the team, with AI coding agents (Anthropic's Claude Code and Claude Opus 5.5, using multiple parallel sub-agents) serving primarily as execution and development assistants. The team led the problem definition, established the overall approach, conducted the literature survey, developed the v2 plan, and made all key technical and research decisions, including model selection, validation and test strategies, deployment choices, and integration decisions.

AI agents were leveraged extensively to accelerate implementation, including GPS processing, the travel-time model, XGBoost correction, journey planning, API and UI development, the real-time layer, evaluation scripts, data processing, and initial documentation and report drafting. Throughout the process, the team provided direction, reviewed outputs, evaluated results, made critical decisions, and guided iterative corrections to ensure the system aligned with the intended objectives.

Google Maps comparison times were gathered through an AI-assisted browser session and subsequently spot-checked by the team. All reported accuracy metrics are generated using reproducible scripts maintained in the project repository. For transparency and traceability, AI-assisted commits include a `Co-Authored-By: Claude` attribution, while `docs/LOG.md` and `docs/handoff/` maintain records of agent activities and contributions.

Overall, AI was used as a tool to accelerate implementation and execution, while the project's conceptualisation, technical direction, methodological decisions, validation, and final oversight remained the responsibility of the team.
